# 1. Discrete Structures

### Focus Areas

* Logic and Proof Techniques
* Sets
* Relations
* Functions
* Mathematical Induction
* Counting Techniques
* Graph Theory
* Trees
* Boolean Algebra

### How to Study

* Understand definitions instead of memorizing.
* Draw diagrams whenever possible.
* Solve at least **10–15 problems** for every topic.
* Keep a notebook of formulas and important theorems.
* Practice previous years' questions every weekend.

### Best Resources

**Books**

# 4. Object-Oriented Programming (C++)

This subject deserves the most attention because it is both theoretical and practical.

### Focus Areas

* Classes and Objects
* Constructors
* Destructors
* Inheritance
* Polymorphism
* Operator Overloading
* Friend Functions
* File Handling
* Exception Handling
* Templates

### How to Study

Every topic should follow this order:

1. Learn the concept.
2. Read the syntax.
3. Write the code yourself.
4. Modify the code.
5. Create your own small program.

Never copy code without understanding it.

### Weekly Coding Goal

* Write **4–5 C++ programs** every week.
* Debug errors yourself.
* Practice in Visual Studio Code, Code::Blocks, or Dev-C++.

### Best Resources

**Books**

* Object-Oriented Programming with C++ – E. Balagurusamy
* The C++ Programming Language – Bjarne Stroustrup

**YouTube**

* CodeWithHarry
* Neso Academy
* Jenny's Lectures CS/IT
* ProgrammingKnowledge

**Websites**

* LearnCpp
* cppreference
* GeeksforGeeks

# Exam Preparation (Last Month)

* Finish the syllabus before the last month.
* Solve **at least 5 previous-year question papers** for each theory subject.
* Revise formulas, definitions, and key concepts daily.
* Practice C++ programs by writing them from memory.
* Focus on understanding repeated question patterns rather than memorizing answers.

## Final Advice

Since your **third semester** will build on the foundations of **C++, Discrete Structures, Digital Logic, and Mathematics-II**, prioritize mastering these four subjects while maintaining regular practice in Financial Management & Accounting. Study consistently rather than cramming, revise every week, solve past Purbanchal University question papers, and write C++ programs by hand as well as on the computer. This approach will help you perform well in your second-semester exams and prepare you for more advanced BIT courses.
