# Previous Questions

Use this folder to store PU BIT153HS previous-year question papers.

## Format

```text
pastquestion.md/
├── README.md
├── 2025-Regular.md
├── 2024-Regular.md
├── 2023-Regular.md
└── 2022-Regular.md
```

## How to use previous questions

1. Solve the paper without notes.
2. Mark repeated questions.
3. Link each question to its relevant unit.
4. Add difficult questions to the unit's `Questions.md`.
5. Revise repeated algorithms and proof patterns.

**Important:** Do not treat unofficial question papers as official unless they have been verified.
