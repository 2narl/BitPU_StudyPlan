# Unit 04 – Questions

1. Define Cartesian product.
2. Define partition with example.
3. Define relation.
4. Explain reflexive, symmetric, antisymmetric and transitive relations.
5. Determine whether a given relation is an equivalence relation.
6. Represent a relation using a digraph.
7. Find paths in a digraph.
8. Perform union, intersection, inverse and composition of relations.
9. Find transitive closure of a relation.
10. Use Warshall's algorithm to find transitive closure.
