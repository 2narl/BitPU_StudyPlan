# Unit 06 – Order Relation and Structure

## Official syllabus
- Partially ordered sets
- Extremal elements of a poset
- Lattices
- Finite Boolean algebra

## 1. Partial order relation

A relation is a partial order if it is:
- Reflexive
- Antisymmetric
- Transitive

A set together with a partial order is called a **poset**.

Notation:
`(P,≤)`

## 2. Poset diagram

A Hasse diagram is a simplified diagram used to represent a finite poset.

It normally omits:
- Self loops
- Transitive edges
- Arrowheads

## 3. Extremal elements

Important terms:
- Minimal element
- Maximal element
- Least element
- Greatest element
- Lower bound
- Upper bound
- Infimum
- Supremum

Do not confuse minimal/maximal with least/greatest.

## 4. Lattice

A poset is a lattice if every pair of elements has:
- A greatest lower bound (meet)
- A least upper bound (join)

Notation:
- Meet: `a∧b`
- Join: `a∨b`

## 5. Finite Boolean algebra

A Boolean algebra is an algebraic structure involving operations such as:
- AND
- OR
- Complement

Important identities include:
- Identity
- Complement
- Idempotent
- Commutative
- Associative
- Distributive
- De Morgan's laws

## Exam focus
1. Check whether a relation is a partial order.
2. Draw Hasse diagrams.
3. Find minimal/maximal and least/greatest elements.
4. Find upper/lower bounds, join and meet.
5. Determine whether a poset is a lattice.
6. Understand finite Boolean algebra.
