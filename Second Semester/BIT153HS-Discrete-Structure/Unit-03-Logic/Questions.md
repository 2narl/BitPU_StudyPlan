# Unit 03 – Questions

## Short questions
1. Define proposition.
2. Define tautology and contradiction.
3. What is logical equivalence?
4. Define conditional statement.
5. Differentiate converse, inverse and contrapositive.
6. Define valid argument.
7. State Modus Ponens and Modus Tollens.
8. Define direct proof and contradiction proof.
9. What is mathematical induction?

## Long questions
1. Construct truth tables for compound propositions.
2. Prove logical equivalence using truth tables.
3. Test an argument for validity.
4. Explain different proof techniques with examples.
5. Prove a summation formula using mathematical induction.
6. Prove divisibility statements using induction.
