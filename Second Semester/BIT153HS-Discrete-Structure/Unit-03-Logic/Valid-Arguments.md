# Valid Arguments

An argument is valid when it is impossible for all premises to be true and the conclusion to be false.

## Common valid forms

### Modus Ponens
`p→q`
`p`
`∴q`

### Modus Tollens
`p→q`
`¬q`
`∴¬p`

### Hypothetical Syllogism
`p→q`
`q→r`
`∴p→r`

### Disjunctive Syllogism
`p∨q`
`¬p`
`∴q`

## Common invalid forms

### Affirming the Consequent
`p→q`
`q`
`∴p`

### Denying the Antecedent
`p→q`
`¬p`
`∴¬q`

## Truth-table test

An argument is valid if there is no row in which all premises are true and the conclusion is false.

Equivalently:

`(P1∧P2∧...∧Pn)→C`

is a tautology.

## Exam definition

**Valid argument:** An argument in which the conclusion logically follows from the premises.
