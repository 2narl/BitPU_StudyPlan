# Unit 01 – Set Theory and Matrices

## Official syllabus
- Overview of sets and set operations
- Sequence
- Matrices
- Mathematical structure

## 1. Sets

A **set** is a well-defined collection of distinct objects.

Example:
`A = {1, 2, 3, 4}`

### Important terms
- Element: an object belonging to a set.
- Empty set: `∅`
- Universal set: `U`
- Subset: `A ⊆ B`
- Proper subset: `A ⊂ B`
- Power set: `P(A)`
- Cardinality: `|A|`

## 2. Set operations

For sets A and B:

- Union: `A ∪ B`
- Intersection: `A ∩ B`
- Difference: `A − B`
- Complement: `A'`
- Symmetric difference: `A Δ B`

### Important laws
- Commutative: `A ∪ B = B ∪ A`
- Associative: `(A ∪ B) ∪ C = A ∪ (B ∪ C)`
- Distributive
- Identity
- Domination
- Idempotent
- Complement
- De Morgan's laws

## 3. Sequence

A sequence is an ordered list of terms.

Example:
`2, 4, 6, 8, ...`

Arithmetic sequence:
`a_n = a_1 + (n-1)d`

Geometric sequence:
`a_n = ar^(n-1)`

## 4. Matrices

A matrix is a rectangular arrangement of numbers.

Example:
`A = [[1,2],[3,4]]`

### Types
- Row matrix
- Column matrix
- Square matrix
- Zero matrix
- Diagonal matrix
- Identity matrix
- Symmetric matrix

### Operations
- Addition
- Scalar multiplication
- Matrix multiplication
- Transpose

## 5. Mathematical structure

A mathematical structure consists of a set together with one or more operations/relations defined on it.

For exam preparation, understand the meaning of a set, operation, and relation and how they form a structure.
