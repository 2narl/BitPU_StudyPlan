# Unit 01 – Examples

## Example 1: Union and intersection

Let `A={1,2,3}` and `B={3,4,5}`.

`A ∪ B = {1,2,3,4,5}`

`A ∩ B = {3}`

`A-B = {1,2}`

## Example 2: Power set

If `A={a,b}`, then:

`P(A)={∅,{a},{b},{a,b}}`

Therefore, `|P(A)|=2^2=4`.

## Example 3: Arithmetic sequence

For `3,7,11,15,...`:

`a=3`, `d=4`

`a_n = 3 + (n-1)4 = 4n-1`.

## Example 4: Matrix addition

`A=[[1,2],[3,4]]`

`B=[[5,6],[7,8]]`

`A+B=[[6,8],[10,12]]`.

## Example 5: Matrix multiplication

`A=[[1,2],[3,4]]`, `B=[[2,0],[1,2]]`

`AB=[[4,4],[10,8]]`.
