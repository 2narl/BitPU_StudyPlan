# Unit 2 — Functions and Counting ⭐⭐⭐⭐⭐

This is an important unit.

### Study

- Functions
- Types of functions
- Functions in computer science
- Permutation
- Combination
- Pigeonhole principle
- Recurrence relations

### Must-Practice Problems

- Find `f(a)`
- Determine whether a function is one-to-one
- Determine whether a function is onto
- Permutation problems
- Combination problems
- Pigeonhole principle problems
- Basic recurrence relations

### Important Formulas

#### Permutation

\[
{}^nP_r = \frac{n!}{(n-r)!}
\]

#### Combination

\[
{}^nC_r = \frac{n!}{r!(n-r)!}
\]

### Remember

> **Permutation = Arrangement**

> **Combination = Selection**

# Unit 4 — Relations and Digraphs ⭐⭐⭐⭐⭐

This is one of the largest units with **8 hours**.

### Study

- Cartesian product
- Relations
- Properties of relations
- Reflexive relations
- Symmetric relations
- Antisymmetric relations
- Transitive relations
- Equivalence relations
- Digraphs
- Paths
- Transitive closure
- Warshall's algorithm

### 🔥 Very Important

Practice **Warshall's algorithm step-by-step**.

Also practice checking whether a relation is:

> **Reflexive + Symmetric + Transitive**

If all three conditions hold, the relation is an **equivalence relation**.

# Unit 7 — Automata, Language and Grammar ⭐⭐⭐⭐⭐

This unit connects discrete mathematics with theoretical computer science and is especially relevant to BIT students.

### Study

- Finite-state automata
- Strings
- Languages
- Regular expressions
- Regular grammars

### 🔥 Focus On

- DFA/NFA basics
- State diagrams
- Strings and languages
- Regular expressions
- Regular grammar
- Constructing finite automata

### Important Automata Representation

A finite automaton can be represented as:

\[
M=(Q,\Sigma,\delta,q_0,F)
\]

where:

- `Q` = finite set of states
- `Σ` = input alphabet
- `δ` = transition function
- `q₀` = initial state
- `F` = set of final/accepting states

# 📖 Exam-Oriented Study Method

For every topic, follow this sequence:

```text
1. Learn the concept
       ↓
2. Memorize the definition/formula
       ↓
3. Study one solved example
       ↓
4. Solve 3–5 problems yourself
       ↓
5. Practice a previous/tutoral question
       ↓
6. Write a short revision note
```

### Recommended ratio

Spend approximately:

- **30%** of study time on theory
- **70%** on problem solving and practice

Discrete Structure becomes much easier when you solve problems regularly.
