## 🎯 Important Execution Rules

1. **Strict 12-Hour Clock:** All slots use standard `AM/PM` notation for simplicity.
2. **Hard Subject Alternating Pattern:** 
   - **Math II** → Day 1
   - **OOP C++** → Day 2
   - **Discrete Structures** → Day 3
   - Repeat cycle seamlessly.
3. **Daily Revision Mandate:** Never skip the 1-hour revision slot. Re-reading previous day's notes doubles memory retention.
4. **Time Extension Flexibility:** If a college project demands extra time, extend Slot 3 by 30–45 minutes without sacrificing sleep.
