- Paths
- Transitive closure
- Warshall's algorithm

## Important Relation Properties

### Reflexive

A relation `R` on `A` is reflexive if:

\[
(a,a) \in R
\]

for every:

\[
a \in A
\]

### Symmetric

If:

\[
(a,b) \in R
\]

then:

\[
(b,a) \in R
\]

### Antisymmetric

If:

\[
(a,b) \in R
\]

and:

\[
(b,a) \in R
\]

then:

\[
a=b
\]

### Transitive

If:

\[
(a,b) \in R
\]

and:

\[
(b,c) \in R
\]

then:

\[
(a,c) \in R
\]

### Equivalence Relation

A relation is an equivalence relation when it is:

> **Reflexive + Symmetric + Transitive**

## 🔥 Very Important

Practice **Warshall's algorithm step-by-step**.

Also practice determining whether a given relation is:

> Reflexive + Symmetric + Transitive

# 📌 Quick Formula Sheet

## Power Set

For a set containing `n` elements:

\[
|P(A)| = 2^n
\]

## Permutation

\[
{}^nP_r = \frac{n!}{(n-r)!}
\]

## Combination

\[
{}^nC_r = \frac{n!}{r!(n-r)!}
\]

## Tree

For a tree with `n` vertices:

\[
E=n-1
\]

## Logical Implication

\[
p \rightarrow q \equiv \neg p \lor q
\]

## De Morgan's Laws

\[
\neg(p\land q) \equiv \neg p\lor\neg q
\]

\[
\neg(p\lor q) \equiv \neg p\land\neg q
\]

## Equivalence Relation

```text
Reflexive + Symmetric + Transitive
```

## Partial Order

```text
Reflexive + Antisymmetric + Transitive
```

## Finite Automaton

\[
M=(Q,\Sigma,\delta,q_0,F)
\]
