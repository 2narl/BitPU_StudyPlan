# Previous Questions — BIT102HS

Use this folder to store PU BIT BIT102HS previous-year question papers, internal questions, practical questions and project briefs for **Mathematics I**.

## Suggested Structure

```text
Previous-Questions/
├── README.md
├── 2082-Regular.md
├── 2081-Regular.md
├── 2080-Regular.md
└── Internal-Questions.md
```

Use the actual year and exam type shown on each paper. Do not create a year file until you have a real question paper to add.

## How to Use Previous Questions

1. Attempt the paper without notes and within the examination time.
2. Mark questions you could not answer.
3. Map each question to its relevant syllabus unit.
4. Identify recurring concepts, but do not assume questions will repeat.
5. Write solutions in a separate notes file.
6. Keep official questions separate from predicted questions.
