# Computer Programming in C

**Course Code:** BIT105CO  
**Credits:** 3  
**Weekly Hours:** Lecture 3 | Tutorial 1 | Laboratory 3  
**Course Type:** Theory + Practical

## Course Objectives

- Understand the basic concepts of structured programming.
- Develop algorithms and flowcharts for simple problems.
- Write, compile, test and debug C programs.
- Use selection, repetition, arrays, functions, pointers, structures and files to solve problems.

## Practical / Laboratory Work

Practise a progressive set of programs:

1. Print messages and perform arithmetic operations.
2. Convert temperature, distance and currency values.
3. Find the largest of two or three numbers.
4. Check odd/even, positive/negative and leap year.
5. Generate multiplication tables and number patterns.
6. Find factorial and Fibonacci series using loops and recursion.
7. Check prime numbers and reverse/palindrome numbers.
8. Find sum, average, maximum and minimum of array elements.
9. Perform matrix addition and multiplication.
10. Search and sort array elements.
11. Perform string length, copy, compare and concatenate operations.
12. Create user-defined functions for common calculations.
13. Demonstrate pointer operations and dynamic memory allocation.
14. Store and display student records using structures.
15. Read from and write to files.

## How to Study

Follow this order for every programming topic:

1. Understand the concept.
2. Learn the syntax and rules.
3. Trace a small example by hand.
4. Write the program without copying.
5. Compile and test normal, boundary and invalid inputs.
6. Debug errors and explain why they occurred.
7. Modify the program to solve a related problem.
