# Computer Programming in C

**Course Code:** BIT105CO  
**Credits:** 3  
**Weekly Hours:** Lecture 3 | Tutorial 1 | Laboratory 3  
**Course Type:** Theory + Practical

## Course Objective

To familiarize students with writing algorithms and developing programs using the C language.

## Detailed PU Syllabus

### Unit 1: Problem Solving with Computer (3 Hrs)
- Problem analysis
- Algorithms and flowcharts
- History and importance of C
- Structure of a C program
- Coding, compilation and execution
- Debugging, testing and documentation

### Unit 2: Elements of C (3 Hrs)
- C tokens
- Escape sequences
- Variables
- Data types
- Constants and literals
- Expressions
- Statements and comments

### Unit 3: Input and Output (4 Hrs)
- Conversion specifications
- I/O operations
- Unformatted and formatted input/output

### Unit 4: Operators and Expression (3 Hrs)
- Arithmetic operators
- Relational operators
- Logical and Boolean operators
- Assignment operators
- Ternary operator
- Bitwise operators
- Increment and decrement operators

### Unit 5: Control Statements (4 Hrs)
- Branching
- Looping
- Exit function
- break and continue statements
- goto statement

### Unit 6: Arrays (6 Hrs)
- Introduction to arrays
- Declaration and initialization of arrays
- Sorting
- Multidimensional arrays
- Strings and string-handling functions

### Unit 7: Functions (5 Hrs)
- Local, global, static and register variables
- Library functions and user-defined functions
- Pass by value and pass by reference
- Recursion
- Use of arrays in functions

### Unit 8: Pointers
- Introduction and importance of pointers
- Reference and dereference operators
- Pointer arithmetic
- Pointers and arrays
- Pointers with multidimensional arrays
- Pointers and strings
- Dynamic memory allocation

### Unit 9: Structure and Union (5 Hrs)
- Introduction to structures
- Arrays of structures
- Passing structures to functions
- Passing arrays of structures to functions
- Pointers to structures
- Nested structures
- Unions

### Unit 10: Files and File Handling in C (4 Hrs)
- Introduction and importance of files
- Opening and closing files
- Input/output functions
- Sequential and random access in files

### Unit 11: Introduction to Graphics (2 Hrs)
- Graphics modes
- Initialization
- Graphics functions

## How to Study

Follow this sequence for each topic:

1. Understand the concept and syntax.
2. Trace a small program by hand.
3. Write the program without copying.
4. Compile and test it.
5. Test boundary and invalid inputs.
6. Debug errors and explain their causes.
7. Modify the program to solve a related problem.
