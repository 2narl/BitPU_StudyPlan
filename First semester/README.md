## 3. Fundamentals of Information Technology — BIT101CO

### Course objective

The course aims to provide basic knowledge of information technology, its components and applications in different fields.

### Unit-wise syllabus transcribed from the supplied text

**Unit 1: Introduction to Computer (4 Hrs)**
- Characteristics and components of computers
- History and generations of computers
- Classification of computers based on purpose, size and technology
- Applications of computers in business, industry, homes, education, training, entertainment, science, medicine and engineering

**Unit 2: Basic Computer Organization and Computer Peripherals (4 Hrs)**
- Block diagram of a computer system
- Input devices: keyboard, mouse and other input devices
- Output devices: monitor, printer and other output devices

**Unit 3: Computer Storage (4 Hrs)**
- Concepts of memory and requirements of storage devices
- Classification and types of storage devices
- ROM and RAM with their types
- Magnetic and optical storage devices

**Unit 4: Computer Software (4 Hrs)**
- Introduction and types of software
- Operating system: definition, functions and types
- Programming languages and their types

**Unit 5: Introduction to Database (4 Hrs)**
- Meaning of data and information
- Concepts and characteristics of database and DBMS
- Database models
- Data warehouse and data marts
- Data mining
- Online Analytical Processing (OLAP)

**Unit 6: Networks and Internet (10 Hrs)**
- Introduction to communication systems and computer networks
- Uses of computer networks
- Network types and topologies
- Network media and network software
- Internet: introduction, features and applications
- Intranet and extranet
- World Wide Web and e-mail
- E-commerce and e-learning
- E-governance and e-banking
- Network protocols: TCP/IP, HTTP, HTTPS, FTP, SMTP, POP3 and IMAP

**Unit 7: Information Security (2 Hrs)**
- Introduction to information security
- Computer crime
- Viruses and security threats
- Cyber law and ethical issues

> **Transcription note:** This unit outline is based on the OCR text shared in the conversation. Check the original PDF for spelling, exact wording and any missing subtopics before treating it as a verbatim official syllabus.

## 4. Study Strategy

- **Mathematics-I:** Understand concepts and formulas, then solve numerical problems regularly.
- **Fundamentals of IT:** Learn definitions, compare concepts, draw diagrams and revise applications.
- **Technical Communication:** Practice grammar, comprehension, formal writing and presentations.
- **Society and Computer Ethics:** Prepare clear notes on social impacts, ethical responsibilities and relevant legal concepts from the official units.
- **C Programming:** Practice writing, compiling, testing and debugging C programs.
- **Project-I:** Follow the project instructions, plan milestones and maintain documentation throughout the semester.
