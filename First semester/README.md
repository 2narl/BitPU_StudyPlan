# First Semester BIT — Purbanchal University

According to the **Purbanchal University Bachelor of Information Technology (BIT), First Semester** course structure, the subjects are **Fundamentals of Information Technology, Mathematics-I, Technical Communication, Society and Ethics in IT, Computer Programming in C, and Project-I**.

The following study strategy follows the same format as the **Second Semester** study plan in this repository. It provides daily study allocation, subject-wise focus areas, study methods, recommended books, YouTube channels, websites, weekly scheduling and exam preparation.

> **Course structure:** 17 credits in total. The subject-wise detailed syllabus and practical topics are available in each subject folder. Always compare them with the latest syllabus and instructions issued by your college.

# 1. Fundamentals of Information Technology

### Focus Areas

- Characteristics, components and generations of computers
- Classification and applications of computers
- Basic computer organization and block diagram
- Input and output devices
- RAM, ROM and storage devices
- System software, application software and operating systems
- Database, DBMS, data warehouse and data mining
- Computer networks, network topologies and network media
- Internet, WWW, e-mail and network protocols
- Information security, cybercrime and cyber law
- Computer hardware, motherboard, BIOS, SMPS and microprocessors
- Emerging technologies: cloud computing, AI, big data, IoT, robotics, VR, AR and blockchain

### How to Study

- Draw and label the block diagram of a computer.
- Prepare comparison tables for RAM and ROM, input and output devices, and system and application software.
- Learn network types, topologies and protocols with diagrams and examples.
- Make short notes for each technology and its applications.
- Practise identifying hardware components and using computer applications in the laboratory.
- Revise definitions and differences regularly.

# 2. Mathematics-I

### Focus Areas

- Matrix algebra and determinants
- Adjoint and inverse of a matrix
- Cramer's rule and systems of linear equations
- Rectangular, polar, cylindrical and spherical coordinates
- Conic sections and translation of axes
- Vectors and vector operations
- Dot product and cross product
- Equations of lines and planes
- Sphere, cylinder, cone and quadratic surfaces
- Applications of differentiation
- Rolle's theorem and Mean Value Theorem
- Maxima and minima
- Taylor's and Maclaurin's series
- Definite integration and its applications
- Functions of several variables and partial derivatives
- Euler's theorem for homogeneous functions

### How to Study

- Learn one formula at a time and write it in a formula notebook.
- Understand the conditions for applying each theorem.
- Solve worked examples before attempting exercises.
- Practise matrix operations, vectors and differentiation step by step.
- Draw coordinate systems and conic sections to understand their properties.
- Solve numerical problems every day.
- Review incorrect solutions and practise similar questions again.

# 5. Computer Programming in C

This subject deserves regular attention because it requires both theoretical understanding and practical coding.

### Focus Areas

- Problem solving, algorithms and flowcharts
- History and structure of C
- C tokens, variables, data types and constants
- Input and output functions
- Operators and expressions
- Branching and looping statements
- Arrays and strings
- Functions and recursion
- Local, global, static and register variables
- Pointers and pointer arithmetic
- Dynamic memory allocation
- Structures and unions
- File handling and file operations
- Introduction to graphics

### How to Study

Every topic should follow this order:

1. Learn the concept.
2. Understand the syntax.
3. Trace a small program by hand.
4. Write the code yourself.
5. Compile and test the program.
6. Find and correct errors.
7. Modify the program to solve a similar problem.

Never copy code without understanding it.

### Weekly Coding Goal

- Write **5–7 C programs** every week.
- Practise at least one problem involving arrays, functions or pointers as you progress.
- Debug errors yourself before checking solutions.
- Practise in Visual Studio Code, Code::Blocks or another C compiler.
- Keep your programs organized by unit and topic.

# 6. Project-I

Project-I helps you apply the C programming and problem-solving skills learned during the semester to a small software project.

### Focus Areas

- Problem identification and information gathering
- Project proposal and objectives
- System requirements specification
- Project scope and limitations
- Algorithms and flowcharts
- Program design and coding in C
- Testing and debugging
- Project results and demonstration
- Project documentation and report writing
- Oral presentation and viva

### How to Study

1. Select a small and achievable problem.
2. Discuss and approve the topic with your supervisor.
3. Identify the users and requirements.
4. Prepare algorithms and flowcharts before coding.
5. Divide the program into manageable functions.
6. Test the program with valid, invalid and boundary inputs.
7. Record project progress and maintain backups.
8. Prepare the report and presentation.
9. Make sure every group member can explain the code and results.

### Suggested Beginner Projects

- Student marks and grade calculator
- Simple library record system
- Personal expense tracker
- Quiz application
- Unit converter
- Contact book
- Basic inventory tracker
- Student record management system

# Monthly Revision Plan

### Week 1

- Complete Unit 1 of every subject.
- Install and test a C compiler.
- Start a formula notebook for Mathematics-I.
- Choose possible Project-I topics and discuss them with your supervisor.

### Week 2

- Complete Unit 2 and revise Week 1.
- Practise C programs using input/output, operators and control statements.
- Practise reading comprehension and formal writing.
- Prepare short notes for Fundamentals of IT and Society and Ethics.

### Week 3

- Complete Unit 3 and revise previous units.
- Solve mathematics problems and write C programs without copying.
- Practise letters, reports and presentation skills.
- Begin or continue the approved project.

### Week 4

- Take one mock test for each theory subject.
- Review mistakes and revise weak topics.
- Complete practical exercises and project milestones.
- Practise previous questions under examination conditions.

> Repeat this four-week cycle for the remaining units, adjusting it to the actual teaching pace and semester calendar.

---

# Exam Preparation (Last Month)

- Finish the syllabus before the final revision period.
- Solve **at least 5 available previous-year question papers** for each theory subject.
- Revise definitions, comparisons, diagrams and important concepts daily.
- Practise mathematics problems under time limits.
- Write C programs from memory and test them on a compiler.
- Practise technical writing formats, comprehension and grammar.
- Prepare examples and case studies for Society and Ethics in IT.
- Revise computer diagrams, network concepts, protocols and hardware components.
- Complete and test the Project-I work; prepare the report and presentation.
- Focus on understanding repeated question patterns rather than memorizing answers.

## Final Advice

Your first semester builds the foundation for the rest of the BIT program. Give special attention to **C Programming, Mathematics-I and Fundamentals of Information Technology**, while regularly practising communication skills, understanding society and ethics, and completing Project-I step by step.

Study consistently rather than cramming. Read concepts, solve problems, write programs, practise communication and revise every week. This will prepare you for your first-semester examinations and make the later BIT subjects easier to understand.
