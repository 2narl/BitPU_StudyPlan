## 5. Overall Study Strategy

- **Mathematics:** Learn formulas and theorem statements, then solve numerical problems.
- **Fundamentals of IT:** Use diagrams and practice office applications in the lab.
- **Technical Communication:** Read, write and speak English regularly; practice formal writing formats.
- **Electrical Circuits:** Draw circuits, understand laws and solve numerical problems step by step.
- **Management:** Use definitions, headings, comparisons and practical organizational examples.
- **C Programming:** Write, compile, test and debug programs regularly.
- **Project-I:** Develop a small C project throughout the semester and document each phase.

## 6. Monthly Revision Plan

1. **Week 1:** Begin first units, set up C compiler and identify project topics.
2. **Week 2:** Continue units, complete IT/electrical practicals and practice formal writing.
3. **Week 3:** Solve numerical and programming exercises; prepare project requirements and flowcharts.
4. **Week 4:** Revise completed units, attempt mock tests and review weak topics.

Repeat according to the actual teaching schedule.
