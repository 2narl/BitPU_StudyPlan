# Fundamentals of Information Technology

**Course Code:** BIT101CO  
**Credits:** 3  
**Weekly Hours:** Lecture 3 | Tutorial 1 | Laboratory 2  
**Course Type:** Theory + Practical

## Course Objective

To provide basic knowledge of information technology, its components and their applications in various fields.

## Detailed PU Syllabus

### Unit 1: Introduction to Computer (4 Hrs)
- Characteristics and components of computers
- History and generations of computers
- Classification of computers based on purpose, size and technology
- Applications of computers in business and industry
- Computers at home
- Computers in education and training
- Computers in entertainment, science, medicine and engineering

### Unit 2: Basic Computer Organization and Computer Peripherals (4 Hrs)
- Block diagram of a computer system
- Input devices: keyboard, mouse and other types of input devices
- Output devices: monitor, printer and other types of output devices

### Unit 3: Computer Storage (4 Hrs)
- Concepts of memory and requirements of storage devices
- Classification and types of storage devices
- ROM and RAM with their types
- Magnetic storage devices
- Optical storage devices

### Unit 4: Computer Software (4 Hrs)
- Introduction and types of software
- Definition, functions and types of operating systems
- Programming languages and their types

### Unit 5: Introduction to Database (4 Hrs)
- Meaning of data and information
- Concepts and characteristics of database and DBMS
- Database models
- Data warehouse and data marts
- Data mining
- Online Analytical Processing (OLAP)

### Unit 6: Networks and Internet (10 Hrs)
- Introduction to communication systems and computer networks
- Uses of computer networks
- Types and topologies of networks
- Network media and network software
- Introduction, features and applications of the Internet
- Intranet and extranet
- World Wide Web and e-mail
- E-commerce, e-learning, e-governance and e-banking
- Introduction to network protocols: TCP/IP, HTTP, HTTPS, FTP, SMTP, POP3 and IMAP

### Unit 7: Information Security (2 Hrs)
- Introduction to information security
- Computer crime, viruses and threats
- Cyber law and ethical issues

### Unit 8: Computer Hardware (7 Hrs)
- Motherboard and its parts
- Slots and daughterboards
- BIOS
- SMPS
- CMOS
- Microprocessors

### Unit 9: Technological Trends in Information Technology (6 Hrs)
- Cloud computing
- Artificial intelligence
- Big data
- Internet of Things (IoT)
- Robotics
- Virtual reality
- Augmented reality
- Blockchain technologies

## Laboratory Works

The syllabus includes practical work in the following areas:

### 1. Basics of Windows and User Interface
- Use the mouse and move icons on the screen.
- Explore My Computer / This PC, Recycle Bin, status bar, Start button and menu bar.
- Open, close and run applications.
- Use Windows Explorer / File Explorer to view files, folders and directories.
- Create and rename files and folders.
- Explore Control Panel/settings: wallpaper, screen saver, date and time, and sound.
- Use right-click options, shortcuts, Notepad and accessories.

### 2. Basic DOS Commands
- Compare DOS and Windows.
- Switch between DOS and Windows environments.
- Create, rename, copy, move and delete files and directories.

### 3. Word Processing
- Open, close and save documents.
- Set up pages, print and navigate a document.
- Select, cut, copy and paste text.
- Format fonts using bold, italic, underline, alignment, size and colour.
- Set line and paragraph spacing.
- Use bullets, numbering and change case.
- Create and format tables; insert/delete rows and columns; set borders and cell dimensions.

### 4. Spreadsheets
- Open and close spreadsheets and work with multiple sheets.
- Enter data and understand cell addressing.
- Create and format tables.
- Copy cells and adjust row/column dimensions.
- Use SUM, AVERAGE, percentage and other basic functions.
- Prepare invoices, budgets, transaction totals and daily/monthly reports.

### 5. Presentations
- Create and save a presentation.
- Add titles, text, pictures and tables.
- Format fonts, bullets and indentation.
- Apply slide design and background.
- Add slide numbers and animations.
- Sort, show and print slides.

### 6. Computer Communication and Internet
- Understand basic computer networks, WWW and websites.
- Browse the web and use search engines.
- Use online communication and e-mail.

### 7. Computer Hardware
- Assemble and disassemble a computer system.
- Install an operating system, utilities and application software.
- Install a printer.
- Perform routine checks and troubleshooting.
- Use virus protection.
- Practise network cabling and Internet connectivity.

## How to Study

- Draw and label the computer block diagram.
- Prepare comparison tables for RAM/ROM, storage devices and software types.
- Memorize the main functions of common network protocols.
- Practise Office applications and file-management tasks in the laboratory.
- Learn hardware components by identifying them on a real computer.
- Prepare examples for databases, cloud computing, AI, IoT and information security.
