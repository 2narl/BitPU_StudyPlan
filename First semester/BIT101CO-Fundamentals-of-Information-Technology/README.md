# Fundamentals of Information Technology

**Course Code:** BIT101CO  
**Credits:** 3  
**Weekly Hours:** Lecture 3 | Tutorial 1 | Laboratory 2  
**Course Type:** Theory + Practical

## Course Objective

To develop an understanding of information technology, computer systems, software, data management, networks, the Internet, information security and the use of IT in different fields.

## Detailed Syllabus and Study Outline

> The unit topics below are transcribed and organized from the BIT101CO syllabus text supplied for this study plan. Check the latest official course handout for exact wording and any amendments.

### Unit 1: Introduction to Computer (4 Hrs)
- Characteristics of computers: speed, accuracy, diligence, storage and versatility
- Basic components of a computer system
- History and generations of computers
- Classification by purpose, size and technology
- Applications in business and industry
- Applications at home, in education and training
- Applications in entertainment, science, medicine and engineering

### Unit 2: Basic Computer Organization and Computer Peripherals (4 Hrs)
- Block diagram of a computer system
- Input-process-output-storage cycle
- Input devices: keyboard, mouse and other input devices
- Output devices: monitor, printer and other output devices
- Functions and uses of common peripherals

### Unit 3: Computer Storage (4 Hrs)
- Memory concepts and storage requirements
- Primary and secondary storage
- RAM and its types
- ROM and its types
- Magnetic storage devices
- Optical storage devices
- Comparison of storage technologies

### Unit 4: Computer Software (4 Hrs)
- Meaning and types of software
- System software and application software
- Operating system: definition, functions and types
- User interface and basic operating-system services
- Programming systems and programming languages
- Machine, assembly and high-level languages
- Translators: assembler, compiler and interpreter

### Unit 5: Introduction to Database (4 Hrs)
- Meaning of data and information
- Database concepts and characteristics
- Database Management System (DBMS)
- Advantages and functions of a DBMS
- Introduction to database models
- Data warehouse and data marts
- Data mining
- Online Analytical Processing (OLAP)

### Unit 6: Networks and Internet (10 Hrs)
- Communication systems and computer networks
- Uses and advantages of computer networks
- Types of networks
- Network topologies
- Network media and network software
- Internet: features and applications
- Intranet and extranet
- World Wide Web and e-mail
- E-commerce and e-learning
- E-governance and e-banking
- Protocols: TCP/IP, HTTP, HTTPS, FTP, SMTP, POP3 and IMAP

### Unit 7: Information Security (2 Hrs)
- Introduction to information security
- Computer crime
- Computer viruses and other security threats
- Cyber law
- Privacy, security and ethical issues

## Practical / Laboratory Study

The laboratory component should develop confidence in using a computer and common desktop applications. Practise the following where they are included in your college laboratory plan:

1. Identify computer components and peripherals.
2. Explore the operating-system interface and settings.
3. Create, organize, copy, move, rename and delete files and folders.
4. Use a word processor to create and format a document.
5. Create a spreadsheet, use basic formulas and prepare charts.
6. Prepare a presentation with text, images and slides.
7. Use the Internet, browsers, search engines and e-mail safely.
8. Demonstrate basic file-management and security practices.

4. **Computer Fundamentals** — P. K. Sinha and Priti Sinha.

## How to Study

- Draw and label the block diagram of a computer.
- Prepare comparison tables for RAM/ROM, primary/secondary storage and system/application software.
- Memorize protocol names with their main purposes.
- Use real-life examples for databases, networks and IT applications.
- Practise the laboratory tasks instead of only reading their steps.

## Focus Areas

- Computer generations and classification
- Input, output and storage devices
- Operating systems and software types
- Database and DBMS concepts
- Network types, topologies and protocols
- Internet services and information security
